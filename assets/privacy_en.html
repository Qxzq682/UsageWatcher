What this program collects

FieldPurposeStored?
Foreground window handle → process IDWhich app is in frontNo (transient)
Full path of the executableIdentify the appYes
Version resource: product / version / publisherReadable namesYes
Process CPU time, disk I/O bytesReal background activityNo (diff only)
Milliseconds since last inputIdle down-clockingNo
Timestamps (start/end)Compute durationsYes

Never collected

  • Window titles, control text
  • URLs / page content
  • Chat content
  • Keyboard input
  • Mouse trails
  • Clipboard
  • Screenshots / recording
  • File contents and names (except the exe's own path)
  • Browser history / bookmarks / passwords
  • Microphone / camera
  • Network traffic content
  • Account / machine name / IP / location
  • Any telemetry or crash reporting

Where data lives

%s
Only this folder (your private per-user folder) is written; the program folder is never written, and no system settings or registry entries are modified (auto-start is off by default and needs your explicit opt-in).

No network

This program contains no networking code, listens on no port and uploads nothing. Verify it yourself: run tools\audit.py — it scans the source for network calls and checks whether this process is listening.

How to delete everything

Click "Clear all data" below; or simply delete the whole folder %s.
