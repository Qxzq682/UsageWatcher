本程序采集什么

字段用途是否落库
前台窗口句柄 → 进程 ID判断哪个程序在前台不落库（瞬时值）
程序可执行文件全路径标识是哪个软件落库
版本资源：产品名 / 版本 / 发布者界面上显示可读名称落库
进程 CPU 时间、磁盘读写字节数判断后台是否真有活动不落库（仅差分）
距上次输入的毫秒数空闲时自动降频省电不落库
时间戳（起止）算时长落库

绝不采集

  • 窗口标题、控件文字
  • 网址 / 网页内容
  • 聊天内容
  • 键盘输入
  • 鼠标轨迹
  • 剪贴板
  • 截屏 / 录屏
  • 文件内容与文件名（exe 自身路径除外）
  • 浏览器历史 / 书签 / 密码
  • 麦克风 / 摄像头
  • 网络流量内容
  • 账号 / 机器名 / IP / 位置
  • 任何遥测或崩溃上报

数据存在哪

%s
只写入这个目录（当前用户的私有目录），不会写程序目录， 也不会修改任何系统设置或注册表项（开机自启默认关闭，需要你主动勾选）。

不联网

本程序不包含任何联网代码，不监听任何端口，不上传任何数据。 你可以自己验证：关掉程序外的一切干扰，运行 tools\audit.py，它会扫描源码里的网络调用并检查本进程是否在监听端口。

怎么彻底删除

点下面的「清空全部数据」删除所有记录；或直接删除整个目录 %s。
